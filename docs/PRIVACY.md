# プライバシーポリシー（草案）

**WakeAtStation（駅ウェイク）** は以下の方針で利用者のデータを扱います。

## 1. 収集する情報

- **位置情報**: 降車駅への接近判定のみに使用します。
  - 端末内で処理し、当アプリのサーバーには送信しません。
- **アラーム・お気に入り設定**: 端末内のローカルストレージに保存します。

## 2. 第三者提供

当アプリは利用者の位置情報を第三者に提供しません。
解析ツール（例: Firebase Analytics）も導入しません。

## 3. 広告

広告は表示しません（買い切りアプリのため）。

## 4. データの削除

アプリをアンインストールすると、保存されたすべてのデータが削除されます。
